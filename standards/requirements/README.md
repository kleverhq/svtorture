# Requirement parts

Each `chapter-NN.toml` or `annex-X.toml` groups the normative, testable
requirements maintained for one IEEE 1800 standard part. `../index.toml` is the
part manifest. The consolidated IEEE 1800-2023 corpus contains 6,719
requirements across 49 nonempty parts; parts without testable requirements have
no TOML document.
